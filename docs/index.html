어디서 렌더할까: 제안 방법 vs Random

3DGS 지도만으로 고른 ACE 학습 시점을 무작위 선택과 비교합니다. 사진을 고르거나 지도를 클릭해 보세요.

지도를 불러오는 중…
오차는 테스트 이미지별 오차의 중앙값입니다. 요약 표는 seed 3개 평균이고, 개별 사진의 추정 결과는 seed 0 모델입니다. 위치 단위는 장면 좌표 단위로, ACE는 m로 표기합니다. Mip360은 COLMAP 좌표라 실제 미터와 다를 수 있으니 같은 씬 안에서 비교해 주세요. 커버리지는 시선 차이 45° 이내의 학습 뷰가 촬영 범위(테스트 카메라가 퍼진 범위)의 10% 거리 안에 있는 테스트 사진의 비율입니다. 실제 테스트 카메라(정답)는 평가에만 썼고 알고리즘 입력에는 쓰지 않았습니다. 제안 방법은 장면의 위쪽 방향까지 지도만으로 추정하고(GT 미사용), 비교한 random 두 종류는 실제 카메라에서 얻은 위쪽 방향을 그대로 써서 비교는 제안 방법에 불리한 조건입니다.
